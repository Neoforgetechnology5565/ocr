# NovaCore HR — HRM Product Demo

A frontend-only, clickable demo of a commercial HRM SaaS product, built for client presentations.

**Open `index.html` in any modern browser.** You don't need a build step, server or backend.

- **Standard HRM:** Dashboard, Employees, Attendance, Leave, Payroll, Benefits, Reports, Settings
- **Premium HRM:** everything in Standard, plus Performance, Recruitment (drag-and-drop ATS), Workflow Automation, Analytics, Documents, Audit Logs and Employee Self-Service

Switch editions with the **STANDARD | PREMIUM** toggle in the top bar. In Standard, Premium modules appear locked and open an upgrade dialog when clicked.

Every person, company and figure in the demo is fictional. Nothing is stored or sent anywhere. "Download Demo" buttons generate CSV files in the browser.

Files: `index.html` · `styles.css` · `script.js` (vanilla JavaScript, no dependencies; Inter font loaded from Google Fonts with a system-font fallback).
